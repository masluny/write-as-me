To be fair, the timeout error is trickier. The API is just slow on cold starts, basically the first call after a deploy takes like four seconds. I bumped the timeout to ten seconds and added one retry, which i think is the pragmatic fix here, even if it is not super elegant.

Also, the flaky login test. Honestly this one drove me crazy for two days. It turns out the test user was shared between two pipelines, so when both ran at the same time one of them would randomly log the other out. I gave each pipeline its own user and at the end of the day that was the whole fix.
